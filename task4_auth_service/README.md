# Auth Service

JWT-аутентификация сервис на Python с использованием FastAPI, PostgreSQL и Redis.

## Функциональность

- Регистрация пользователя
- Авторизация с JWT токенами (access + refresh)
- Обновление токенов
- Обновление данных пользователя
- Просмотр истории входов
- Выход из системы

## Технологии

- FastAPI
- PostgreSQL
- Redis
- JWT токены
- Docker & Docker Compose
